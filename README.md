💳 Digital Payment Fraud Analytics

📌 Project Overview

Digital Payment Fraud Analytics is a data analysis project that focuses on identifying fraudulent credit card transactions and understanding fraud patterns using Python, SQL, Machine Learning, and Power BI.

🎯 Project Objectives

- Analyze credit card transactions.
- Identify fraudulent and normal transactions.
- Perform data cleaning and exploratory data analysis.
- Analyze fraud patterns using SQL.
- Build a Machine Learning model for fraud detection.
- Create an interactive Power BI dashboard.

🛠️ Tools & Technologies

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- MySQL
- Power BI
- VS Code

📂 Dataset Information

- Total Transactions: 283,726
- Normal Transactions: 283,253
- Fraud Transactions: 473
- Missing Values: 0

Dataset Source: "Credit Card Fraud Detection – Kaggle" (https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

🐍 Python & Machine Learning

- Data inspection and cleaning
- Exploratory Data Analysis (EDA)
- Duplicate checking
- Outlier visualization
- Feature scaling
- Random Forest Classifier
- Model evaluation using confusion matrix, classification report, and average precision score

🗄️ SQL Analysis

SQL queries were used to analyze:

- Total transaction count
- Fraud vs normal transactions
- Average and maximum transaction amounts
- High-value fraudulent transactions
- Fraud rates across time intervals
- Fraud detection using transaction features
- Transaction amount ranges

📊 Power BI Dashboard

The interactive dashboard includes:

- Total Transactions
- Fraud Transactions
- Normal Transactions
- Fraud Rate
- Normal vs Fraud Transaction Share
- Fraud Transactions by Amount Range
- Fraud Transactions by Elapsed Hour
- Transaction Class Slicer
- Transaction Amount Slicer

🔍 Key Findings

- 283,726 transactions were analyzed.
- 473 transactions were fraudulent.
- Fraud rate was approximately 0.17%.
- A SQL rule using V14 < -5 and Amount > 100 flagged 89 transactions, of which 73 were actual fraud cases.
- The dataset has a highly imbalanced class distribution.

🚀 Project Outcome

This project helped develop practical skills in data cleaning, exploratory data analysis, SQL querying, machine learning, and Power BI dashboard development.
